# evaluacion2-busqueda-raices

Se compararon seis métodos de búsqueda de raíces:
- Bisección
- Falsa posición
- Punto fijo
- Secante
- Newton-Raphson
- Newton-Raphson mejorado
Aplicando también diferentes tipos de funciones (Polinómicas, logarítmicas, exponenciales, trigonométricas, mixta y una con raíz doble)

## Cómo ejecutar

Tan solo hay que ejecutar main. Ese archivo hace que los demás se ejecuten también

## Qué hacen los demás scripts

Los demás scripts (no main) se encargan de aplicar los distintos métodos numéricos mencionados anteriormente a diferentes funciones, mostrando la raíz encontrada, generando gráficas de el error en cada iteración, gráficas de la función mostrando que chocan con el eje x (la raíz), y generan un archivo csv mostrando los valores de 'x' y 'f(x)'.
